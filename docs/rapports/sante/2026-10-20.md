## Réparations

- **`js/motion.js` : sélecteur sans `:is()`** (incident `JS-095C84`). `querySelectorAll('main section:not(.hero)
  :is(.eyebrow, …)')` lève une `SyntaxError` sur les navigateurs sans `:is()` (Safari < 14, Chrome < 88), ce qui
  arrêtait le script de l'accueil (inclinaison de l'éventail, retournement des cartes Pouvoir). Sélecteur développé
  en quatre sélecteurs simples ; vérifié sur l'accueil en ligne avec Playwright : mêmes 20 éléments, même ordre.
  Test `scripts/test/client-js.test.mjs` (rouge avant le correctif, vert après), leçon dans `_notes/lecon.md`.
  PR de ce run ; vérification en ligne après fusion : `js/motion.js` publié sans `:is(`.
